KeyPale ヘルプ

Tekeyチャットパレット用エディタの使い方

KeyPale とは

KeyPale は、Tekey 用のチャットパレット（シナリオテキスト）を編集するためのデスクトップアプリです。複数タブでシナリオを管理し、スニペット・変数で定型文を素早く挿入できます。プレビューで見た目を確認しながら、Tekey 形式の JSON にエクスポートして Tekey で利用できます。

画面の構成

タイトルバー・ウィンドウ

  • 左側 … メニューボタン（≡）とアプリ名「KeyPale」があります。
  • 右側 … テーマボタン（🎨）と、OS のウィンドウボタン（最小化・最大化・閉じる）があります。テーマボタン（🎨）をクリックすると、ダーク・ライト・セピア・グリーンの 4 種類のテーマカラーから切り替えられます。ウィンドウ右上のボタンでウィンドウの最小化・最大化・閉じるができます。
  • メニュー … 左上の ≡ から「ファイル」「Tekey連携」「表示」「設定」「ヘルプ」を開けます。
  • パネル … 画面は複数のパネルに分かれており、ドラッグで位置やサイズを変えられます。レイアウトは終了時に自動保存されます。

主なパネル

  • スニペット … 登録した定型文の一覧。クリックでエディタに挿入。パネル上部の ⋮ メニューで「読込 (JSON)」「保存 (JSON)」「スニペットを初期に戻す」ができます。
  • 変数 … 名前と値の一覧。{変数名} がエディタ・プレビューで値に置き換わります。パネル上部の「全タブの変数を参照」で、全タブ共通の変数を使うか切り替えられます。⋮ で読込・保存 (JSON)。
  • エディタ … シナリオを書くメインの編集エリア。タブで複数シナリオを切り替え。上部に「ラベル」「名前」入力やカラーパレット（🎨）、エディタオプション（▼）があります。
  • プレビュー … Tekey 書式でレンダリングした結果を表示。フォントサイズ・行間・演出表記の表示 ON/OFF・背景などが変更できます。あくまでプレビューであり、お使いの環境やブラウザによって実際の Tekey での表示と違う点があります。参考までに使用してください。

基本操作

タブ

エディタ上部の「＋」で新規タブを追加。タブの × で閉じます。各タブには「ラベル」（タブに表示する名前）と「名前」（プレビューで使うキャラ名）を設定できます。タブの並び順や開いているタブは終了時に保存され、次回起動時に復元されます。

編集

エディタでは通常のテキスト編集に加え、右クリックメニューから「全行先頭に全角スペース」「選択行の先頭に全角スペース」が使えます。オプション（▼）から全角・半角スペースのハイライト、改行を表示（各行の末尾に ↵ マークを表示）も有効にできます。

検索・置換

Ctrl+F で検索パネル、Ctrl+H で置換パネルを開けます。検索語・置換語のほか、正規表現や大文字/小文字の区別を指定できます。テキストを選択した状態で「全置換」を押すと、選択範囲内だけを置換します。選択していない場合は全文が対象です。

ファイル操作

  • 開く (txt) … テキストファイルを開き、内容を現在のタブまたは新規タブに読み込みます。
  • JSON からタブを開く … KeyPale 形式または Tekey 形式の JSON を開き、タブを復元します。
  • 上書き保存 (txt) … 現在のタブの内容を、最後に開いた（または保存した）テキストファイルに上書き保存します。
  • 名前を付けて保存 … 新しいファイル名を指定してテキストで保存します。

テキストで保存する場合は「開く」「上書き保存」で .txt、JSON でタブをやりとりする場合は「JSON からタブを開く」と「Tekey連携」の保存を使い分けてください。

Tekey 連携（JSON）

メニュー「Tekey連携 (JSON)」から、Tekey で読み込める形式の JSON を保存できます。

  • 現在のタブを保存 (.json) … アクティブなタブ 1 つを Tekey 形式の JSON で保存します。
  • 全タブまとめて保存 (.json) … 開いている全タブを 1 つの JSON にまとめて保存します。

保存した JSON を Tekey 側で読み込んで、チャットパレットとして利用できます。

スニペット

よく使う文言を登録しておき、一覧からクリックでエディタに挿入できます。

追加

スニペットパネル内で「＋」や「スニペット追加」で、表示名と内容を入力して保存します。ショートカット（任意）欄にキー（例: Alt+Shift+A）を指定すると、エディタにフォーカスがあるときにそのキーを押すだけで、そのスニペットの内容がカーソル位置に挿入されます。入力欄にフォーカスを置いてキーを押すと、そのキー組み合わせが記録されます。

編集・削除

一覧の項目を右クリックして「編集」または「削除」を選びます。編集画面でもショートカットの変更・削除ができます。

読込・保存 (JSON)

パネルヘッダの ⋮ メニューから「読込 (JSON)」「保存 (JSON)」で、スニペット一覧をファイルに出し入れできます。別環境やバックアップに便利です。

変数

「変数名」と「値」を登録しておくと、エディタやプレビュー内の {変数名} がその値に置き換わります。

定義の優先順位

  • 同じタブ内の //変数名=値 が最優先。
  • 変数パネルに登録した値がその次。「全タブの変数を参照」ON のときは、全タブ共通の変数が対象になります。

追加・編集・削除

変数パネルで「＋」や「変数追加」から名前と値を入力。一覧を右クリックで「編集」「削除」ができます。⋮ メニューで「読込 (JSON)」「保存 (JSON)」も可能です。ショートカット（任意）を追加・編集モーダルで設定すると、エディタにフォーカスがあるときにそのキーを押すだけで {変数名} がカーソル位置に挿入されます。

Tekey 書式の説明

プレビューおよび Tekey で解釈される主な書式です。

プルダウン（折りたたみ）

  • ### 見出し … 親プルダウンを開始。
  • #### 子見出し … 子プルダウンを開始。
  • ### または #### のみの行 … 直前の同じ種類のプルダウンを閉じます。

発言行と名前・色・演出

通常の行は「名前：本文」として表示されます。名前と色はツールバーの「名前」とパレット（🎨）で設定し、行末の @ コマンドで上書きできます。

  • @[name]:表示名 … その行の表示名を変更。
  • @#RRGGBB … その行の名前の色を指定（例: @#FF0000）。
  • @演出名 … 演出表記（プレビューで「演出表記を表示」ON のとき表示）。

変数

//変数名=値 でそのタブ内の変数を定義。{変数名} で参照すると値に置き換わります。

その他

  • |漢字《よみ》 または |漢字(よみ) … ルビとして表示。
  • \n … 改行に変換。

プレビュー

プレビューパネルでは、エディタの内容を Tekey 書式でレンダリングして表示します。

  • フォントサイズ・行間 … ツールバーのスライダーで調整。
  • 演出表記 … 「演出表記を表示」の ON/OFF で、@ の後の演出名などを表示するか切り替え。
  • 背景 … 暗い・明るい・透明などから選択可能。
  • 検索 … パネル内の検索ボックスでプレビュー本文を検索できます。

オプション設定

メニュー「設定」→「オプション設定...」で開きます。

基本カラー

現在のテーマ（ダーク／ライト／セピア／グリーン）の配色を変更できます。親プルダウン・子プルダウンの色、エディタのリンク・全角／半角スペースのハイライト色・改行マーク（「改行を表示」ON のとき表示される ↵ の色）、プレビューの演出表記の色などを設定可能です。

カスタムハイライト

キーワードを登録すると、エディタ内でその語に色や背景を付けて強調表示できます。1 行に 1 キーワードで複数登録でき、JSON で保存・読込もできます。

定型文設定

スニペットほどではない短い定型文を、ショートカットキーでエディタに挿入できます。オプションの「定型文設定」タブで、ショートカット（例: Alt+Shift+A）と挿入する文字列（例: \n や @#424242）を登録します。一覧は右クリックで編集・削除できます。エディタにフォーカスがあるときに登録したキーを押すと、その文字列がカーソル位置に挿入されます。スニペットや変数と同様、ショートカット入力欄にフォーカスを置いてキーを押すとキー組み合わせが記録されます。

ショートカット

各操作に割り当てるショートカットキーを変更できます。重複や不正な形式の場合は保存できずエラー表示されます。「ショートカットを初期値に戻す」でデフォルトに戻せます。

レイアウト初期化

メニュー「設定」→「レイアウト初期化」で、パネルの配置を初期状態に戻します。レイアウトが崩れたときに使ってください。
